
LOS ARCHIVOS REACT QUE EXTENSION TIENEN?

Los archivos de React tienen la extensión .jsx (la más común para componentes React) o .js (JavaScript plano, también válido).

Si usas TypeScript con React, las extensiones son .tsx y .ts respectivamente.

En resumen:

.jsx → componentes React en JavaScript
.js → JavaScript (puede incluir React, pero sin la convención JSX explícita)
.tsx → componentes React en TypeScript
.ts → TypeScript sin JSX
La mayoría de proyectos modernos creados con Vite o Create React App usan .jsx para componentes y .js para archivos de utilidades o configuración.
